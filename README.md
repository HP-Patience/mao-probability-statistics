# 概率论与数理统计学习记录

本项目用于按照茆诗松、程依明、濮晓龙《概率论与数理统计教程》第三版，系统学习概率论与数理统计。

学习目标是逐步掌握定义、定理、证明、例题类型和应用，并以教材章节为基准追踪覆盖情况。

## 文件结构

```text
├── agent.md                         教学规则与数学表达规范
├── 概率论与数理统计/
│   ├── 学习进度.md                  当前学习位置与掌握状态
│   └── 教材/
│       ├── chapters/                 按章拆分的教材 Markdown
│       ├── auto/                     全书教材 Markdown
│       └── *.pdf                     教材 PDF
```

教材目录还包含正文所需的图片资源。

## 学习方式

- 严格按教材章节顺序推进，每次学习一个小知识点或证明步骤。
- 讲解区分定义、条件、结论、证明和例子，不把“讲过”直接视为“掌握”。
- 已学习内容重新遇到时作为复习，重点检查条件、推理和概念之间的联系。
- 数学公式采用适合手机阅读的纯文本形式；集合差写成 `B − A`。
- 具体进度和下一步安排以 [学习进度](概率论与数理统计/学习进度.md) 为准。

## 开始或恢复学习

先阅读 [agent.md](agent.md)，再阅读 [学习进度](概率论与数理统计/学习进度.md)，从进度文件记录的起点继续。

教学期间不自动修改进度文件。只有明确要求同步或记录进度时，才更新学习记录。
