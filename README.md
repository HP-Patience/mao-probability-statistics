## 学习方式

- **小步推进**：每轮集中学习一个小知识点或证明中的关键步骤。
- **重视推理**：准确说明定义的对象、定理的条件和结论，用具体例子辅助理解。
- **按理解调整**：区分“未讲”“已讲待检查”“已掌握”“需复习”“暂缓”，不把讲过直接视为掌握。
- **保持覆盖可追踪**：教材正文核验后，按章、节核对知识点；暂缓内容注明原因并安排回补。
- **适配手机阅读**：数学公式使用纯文本，例如 `P(A并B) = P(A) + P(B) - P(A交B)`。
